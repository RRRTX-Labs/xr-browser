# xr-browser (meta repository)

XR Browser by RRRTX Systems — governance, build/release, and documentation
surface. The product code lives in the sibling `xr-core` repository
(Plan §7.1: two repos + helpers; this is the meta repo).

**Status:** Phase P1 in progress — see `docs/state/repo-map.md` (created in
P1) for what exists vs. what is planned. Nothing beyond P1 artifacts exists
yet; this repository deliberately contains no build system, no patches, and
no source code (those belong to P2/P3/P5).
